# Security Policy

## Supported Versions

Only the latest published version of git-purge-cli receives security
updates.

| Version | Supported |
| ------- | --------- |
| 0.1.7 and later | Yes |
| Before 0.1.7 | No |

## Reporting a Vulnerability

If you find a security issue, please report it privately rather than
opening a public GitHub issue — use GitHub's private vulnerability
reporting feature:

https://github.com/Mayen007/git-purge/security/advisories/new

Include a description of the issue, steps to reproduce it, and the
affected version. Expect an initial response within a few days.
